# 夏令营 / 预推免 自动填表助手（Chrome 扩展）

> 用于自动填写夏令营、预推免、推免服务系统中的个人信息表单。所有数据仅保存在浏览器本地，不上传服务器。

## 功能

- 一键识别网页表单并自动填充个人信息。
- 支持文本框、下拉框、单选框、多选框、文本域等常见控件。
- 支持 `chsi.com.cn / chsi.cn`（研招网、推免服务系统）等常见系统的专门适配。
- 支持 iframe 嵌套表单。
- 个人信息管理页面：基本信息、联系方式、教育背景、证件、家庭、成绩英语、文书、获奖、论文、项目经历。
- 支持 JSON 导入/导出，方便备份和跨设备迁移。

## 安装

1. 克隆或下载本仓库。
2. 打开 Chrome → `chrome://extensions/`。
3. 打开右上角「开发者模式」。
4. 选择「加载已解压的扩展程序」，选择本仓库根目录。
5. 扩展图标会出现在浏览器工具栏。

## 使用

1. 右键点击扩展图标 → 选择「选项」（或点击弹窗中的「管理个人信息」），填写你的个人资料并保存。
2. 打开需要填写的夏令营/预推免报名页面。
3. 点击扩展图标，点击「一键填表」。
4. 扩展会自动匹配页面字段并填充。填充完成后，请人工复核一遍再提交。

## 隐私说明

- 个人资料通过 `chrome.storage.local` 保存在本地，不会同步到服务器。
- 扩展不会主动访问任何外部网络接口。
- 建议将配置文件备份到安全位置。

## 添加新的学校/系统适配

如果目标报名系统使用了特殊字段名或表单结构，可以复制 `src/content/adapters/generic.js`，命名为对应系统（如 `tsinghua.js`），在 `match` 中判断域名，在 `fill` 中补充自定义映射，然后在 `manifest.json` 的内容脚本列表中加入该文件。
